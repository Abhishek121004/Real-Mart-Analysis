# 🛒 Real Mart Sales Analysis

## 📌 Project Overview
This project analyzes retail sales data of Real Mart using Power BI to uncover business insights and improve decision-making.

## 🧰 Tools Used
- Power BI
- Excel
- Data Visualization
- DAX

## 📊 Key KPIs
- Total Sales
- Total Profit
- Total Orders
- Category-wise Performance
